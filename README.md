# РОП без суеты

Интерактивный русскоязычный карьерный конспект по ключевым идеям книги Майка Вайнберга **Sales Management. Simplified.**

## Возможности

- 8 управленческих уроков;
- самодиагностика руководителя продаж;
- практические B2B-ситуации;
- персональный план развития на 30 дней;
- сохранение прогресса и заметок в браузере;
- экспорт плана в TXT;
- адаптивный интерфейс для компьютера и телефона.

Это самостоятельный учебный материал, а не перевод и не замена оригинальной книги.
