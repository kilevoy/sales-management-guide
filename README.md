# Интерактивные конспекты по управлению продажами

Один GitHub Pages-сайт с отдельными интерактивными страницами по книгам:

1. **Mike Weinberg — Sales Management. Simplified.** — главная страница.
2. **Mark Roberge — The Sales Acceleration Formula** — раздел `/sales-acceleration/`.

## Возможности

- управленческие уроки и B2B-ситуации;
- самодиагностика и калькуляторы;
- персональные планы внедрения;
- сохранение прогресса и заметок в браузере;
- экспорт планов в TXT;
- адаптивный интерфейс для компьютера и телефона.

Это самостоятельные учебные материалы, а не переводы и не замена оригинальных книг.
